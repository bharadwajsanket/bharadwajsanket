## Work

### VYOM — Core Language & Runtime `C`

A complete programming language built from scratch in C: lexer, parser, execution engine, scoped runtime, fixed-size arrays (1D & 2D), strict type enforcement, and deterministic memory handling.

No LLVM. No garbage collector. No hidden runtime.

Manual memory management. Explicit semantics. Predictable execution.

> *What you write is exactly what runs.*

**Runtime guarantees:**

- Strict typing — no silent coercion
- Bounds-checked arrays (1D & 2D, row-major layout)
- Immutable strings
- Loop-scoped execution frames
- No shadowing ambiguity
- Deterministic cleanup (`exit()` guarantees memory release)

**Why it exists:**

Built to go deep on parsing discipline, expression evaluation pipelines, scope resolution and call-frame design, runtime safety without GC, memory layout decisions, and how minimal languages scale without accreting complexity.

Vyom Core v1.0 is frozen. Semantics will not change. Future layers (stdlib, tooling, ecosystem) extend from the outside — never modify the core.

### WANDROUS — Offline-First Travel Platform `React · TypeScript · Vite`

Full offline capability via service workers and PWA architecture. i18n across 6+ languages. Zero backend dependency at runtime. Edge deployed.

Built under a hard constraint: assume no network. That constraint forces clear separation between what genuinely requires a server and what is habitually outsourced to one. Architecture becomes intentional rather than convenient.

`offline-first` · `6+ languages` · [→ Live](https://wandrous.vercel.app)

---

### PORTOS — Browser OS `Vanilla JS · CSS3`

Window management, virtual file structure, drag interactions, and consistent 60fps rendering — built without frameworks or external abstractions.

An exercise in pushing the DOM to its measured limits: tracking reflow/repaint cost, controlling layout thrash, and finding the real performance ceiling before reaching for libraries.

`zero dependencies` · `60fps target` · [→ Live](https://portos-new.vercel.app)
