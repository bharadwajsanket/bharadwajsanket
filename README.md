**Programming Language & Runtime**

[![C](https://img.shields.io/badge/C-000000?style=flat-square&logo=c&logoColor=A8B9CC)](#)&nbsp;
[![Manual Memory](https://img.shields.io/badge/MANUAL_MEMORY-000000?style=flat-square)](#)&nbsp;
[![No GC](https://img.shields.io/badge/NO_GC-000000?style=flat-square)](#)&nbsp;
[![v1.0](https://img.shields.io/badge/v1.0_STABLE-000000?style=flat-square)](#)

A complete programming language implemented from scratch in C — handwritten lexer, recursive descent parser, scoped runtime execution, deterministic memory handling, and a fixed-size array model.

Built to understand the full path from **source text → execution** without relying on external compiler infrastructure. No LLVM. No GC. No magic.

> *What you write is exactly what runs.*

**Architecture decisions:**
- Strict typing — no silent coercion
- Bounds-checked arrays, row-major layout
- Immutable strings — eliminates a class of bugs
- Deterministic cleanup via `exit()`

*Core v1.0 is frozen. Future layers extend from the outside.*

## ◈ &nbsp;Principles

```
simplicity  >  cleverness      —   if it needs explaining, it isn't done
correctness >  speed hacks     —   reliability is the base layer, not a feature
clarity     >  abstraction     —   code should explain itself
users       >  theory          —   software that fails production isn't software
depth       >  hype            —   build systems, not experiments
execution   >  ideas           —   shipping is the only metric that compounds
```
